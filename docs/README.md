* **[System Specification](../spec.md):** Full information architecture, functional systems, user workflows, and quality acceptance criteria.
* **[Project Roadmap](../roadmap.md):** Development phases, completed milestones, and upcoming feature enhancements.
* **[Root Readme](../README.md):** Quickstart guide, local development workflow, and tabletop operating manual.
